# Ticket Application System

##  Overview
The **Ticket Application System** is a Windows Forms application developed in C#.  
Designed to calculate ticket prices based on user input such as passenger details, travel category, and distance.

This project was developed as part of a group assignment, demonstrating the use of software development principles, user interface design, and version control using GitHub.


## Features
- Capture passenger information (Name, Age, Gender)
- Select travel category
- Input travel distance
- Automatic ticket price calculation
- Discount logic based on conditions
- User-friendly Windows Forms interface
- Input validation for accurate data entry


## Technologies Used
- **C#**
- **Windows Forms (.NET Framework)**
- **Visual Studio**
- **Git & GitHub** (Version Control & Collaboration)
